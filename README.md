💰 Expense Tracker (MERN)

A full-stack Expense Tracker application built using the MERN stack (MongoDB, Express, React, Node.js).
Track your daily expenses, manage categories, and visualize your spending with interactive charts.

🏗️ Installation (Local Setup)

Clone the repository:

git clone https://github.com/shashanthroyal/SpentWise.git
cd SpentWise

Backend Setup
cd server
npm install


Create a .env file:

MONGO_URI=your_mongo_connection_string
JWT_SECRET=your_secret_key
PORT=5000


Run server:

npm run dev

Frontend Setup
cd client
npm install


Create a .env file:

VITE_API_URL=http://localhost:5000/api


Run client:

npm run dev
